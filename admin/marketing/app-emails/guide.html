Testing guidelines
One thing at a time
Test one feature, then report what you found before moving on.
Try it twice
If something breaks, try the same steps again and say if it happens every time.
Small things count
A typo, a button in the wrong place, a slow screen: all worth a report.
Keep it private
Never type passwords or personal details in a report, and cover them on the screenshot.
Common mistakes to avoid
Many bugs in one report
Send one report per problem, so each can be fixed and marked done.
Only a title
Add what you did and what you expected, even in Hinglish.
No screenshot
Use Report so the screen is added for you.
Guessing the cause
Just describe what you saw. We'll find the reason.
