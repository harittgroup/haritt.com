The Haritt mail pattern

One skeleton for every mail. Haritt Group colour and 3D logo.

  1. Logo and brand name. Small. No big header image.
  2. "Hi Yash Khandelwal," or a plain one-line title.
  3. One or two short sentences. No marketing words.
  4. ID or code box. The one thing they must see.
  5. Up to 3 numbered steps. Only if there is something to do.
  6. One button. Never two.
  7. One small grey line. Time, expiry, privacy.
  8. Footer. Brand name only.

The only exception

Danger mails (expiry, failed jobs) keep the red header, so nobody misses them.

Plain-text version, hidden preview line, no big images and one button in every mail. Haritt Group mails never mention Developers or HV Verse. HV Verse mails never show Haritt, except the footer line.
