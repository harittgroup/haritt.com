# Haritt Developers brand guidelines

Role: Digital services & technology brand. Website: https://developers.haritt.com.

The client-service brand for development, branding, marketing, lead generation and AI. Dark, premium surfaces with a red-to-orange growth gradient.

Theme: Dark theme with light content sections on the same page. No user-switchable light/dark mode.

## Logos
- Primary logo (3D circle): https://haritt.com/brand-assets/haritt-developers/logos/haritt-developers-3d-circle.png (PNG). Flame icon in an orange glossy circle. 1024 × 1024, transparent background.
- Flat circle: https://haritt.com/brand-assets/haritt-developers/logos/haritt-developers-flat-circle.png (PNG). Flat version for small sizes, favicon and single-colour use.
- Compact / icon (256px): https://haritt.com/icons/haritt-developers.png (PNG). Header, footer and cross-brand cards (3D circle).
- Previous badge (retired): https://haritt.com/brand-assets/haritt-developers/logos/haritt-developers-previous-badge.png (PNG). Retired in November 2026. Kept for reference only, do not use.

Not available: Monochrome logo; Wordmark as a file (the site sets Haritt Developers in Sora Bold).

## Usage
- Use the logo files as supplied. Never stretch, squash, rotate, recolour or add effects.
- Minimum size: 24px on screen for circular badges and app icons; 32px or larger when the text inside must be readable.
- Clear space: keep at least 25% of the logo's width empty on every side.
- Circular badges and app icons work on light and dark backgrounds; avoid busy photos behind them.
- Keep each brand in its own colours and fonts. Do not mix tokens across brands.
- Cross-brand links: show the venture's own logo and name, and link to its own website.
- Headers: logo plus brand name only; no parent name beside a venture's name. Only the HV Verse site footer says "A Haritt venture".
- Naming: brand-assets/<brand>/logos/<brand>-<variant>.<ext>; CSS variables use the brand prefix (--hg-, --hd-, --hvw-).

## Fonts
- Sora: Headings, display, brand name, weights 600, 700. Google Fonts · SIL Open Font License 1.1
- Inter: Body, UI, forms, weights 400, 500, 600. Google Fonts · SIL Open Font License 1.1

Tokens: colors.css, typography.css, tokens.json in this folder. They document the live site; changing them does not change the website.
